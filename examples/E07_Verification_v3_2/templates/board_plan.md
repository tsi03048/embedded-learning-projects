# 보드 검증 계획 — 미실행

대상은 기존 E05 프로젝트 중 사용할 Target을 먼저 확정한다. E07 PC 소스를 MCU에 다운로드하지 않는다.

- Target·소스 SHA/Commit·기존 ZIP 버전:
- STM32F103VET6 / LQFP100, 보드 Revision·실물 부품 확인:
- 회로·점퍼·전원·ADC 기준전압·입력 허용 범위: 기존 준비 페이지와 DS 조건 대조
- Compiler: Arm Compiler 6.22 / 최적화 / 실제 빌드 로그·AXF 해시:
- B-E07-01: 새 측정의 DR·sample_generation·q_gen·active_gen·문장 대응을 기존 E05 절차로 비교
- B-E07-02: 마지막 데이터 TC 인정 뒤 보고 완료 누계와 PC 수신을 별도로 기록
- B-E07-03: 재시작 전 자료가 새 회차로 되살아나지 않는지 기존 E05 절차로 비교
- 실행 전 예상·중단점·자극·측정 장비·원문 기준:
- 실제 관찰 / Raw log·RAM·파형 / 판정: 모두 미실행

정지 중 RAM 관찰은 연속 운전 시간 측정이 아니다. ms_tick은 물리 입력 발생 시각의 증명이 아니다. 제한 시간 요구를 추가하려면 시작·끝 사건, 한계와 근거, 계측 방법을 먼저 합의한다.
