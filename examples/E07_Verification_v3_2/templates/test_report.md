# 시험 보고서 — 복사해서 새 실행에 사용

- Run ID / 날짜·시간대 / 실행자:
- Req ID / Test ID / 시험표 버전:
- 범위: PC 모델 / MCU 보드 / 조합 / 시스템 중 명시
- 소스 경로·SHA256 또는 Commit:
- 빌드 명령·컴파일러 버전·최적화·실행 환경:
- 초기 상태·입력·순서·실행 전 예상:
- 실제 결과·Raw log 경로·로그 줄:
- 판정: 미실행 / PASS / FAIL / BLOCKED
- 차이·원인 가설·확정 근거:
- 수정 파일·차이 / 재시험 대상·새 Run ID:
- 구현·리뷰·시험·통합 담당과 각자 설명한 내용:

모든 칸은 본인 실행으로 채운다. 제공 evidence/reference는 편집자의 참고 실행이며 본인 결과가 아니다.
