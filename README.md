# Embedded Learning Projects

Open103V (STM32F103VET6), Raspberry Pi 4, and final project learning examples.

The `examples/` directory contains the existing STM32 and PC practice packages, organized by original package name. Read each package's instructions before use. STM32 examples use Arm Compiler 6.22 where stated. Builds and PC tests do not imply physical board verification. Raspberry Pi and final project materials can be added as they are developed.
