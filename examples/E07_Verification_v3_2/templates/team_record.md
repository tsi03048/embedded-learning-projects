# 협업·인계·개인 기여 기록

먼저 1명이 동일 E07 PC 실행을 재현한다. 팀은 그 다음 같은 시험표를 공유한다. 인원·경력은 현재 사실을 확인해서 적는다.

|회차·산출물|구현/원본 추적|리뷰|시험|통합|직접 남긴 증거|
|---|---|---|---|---|---|
|T-PC-01~04|미정|미정|미정|미정|미작성|
|T-FAULT-01|미정|미정|미정|미정|미작성|

구현 변경이 없으면 '기존 코드 추적'으로 적는다. 기존 예제나 동료 작업을 본인 구현으로 쓰지 않는다.
인계: 입력·반환·변경되는 상태·실패 시 보존값 → 파일·함수·실제 몸체 → 실행 명령·로그 → 미검증 범위.
혼자라면 같은 역할을 시간차로 수행하고 독립 리뷰를 받지 않았다고 기록한다. 네 명이면 다음 산출물에서 역할을 교대하고 입문자를 문서 역할에 고정하지 않는다.
발표: 문제 → 예상·근거 → 본인 작업 → 재현 결과 → 한계. 이번 실적은 기존 소스 실행·요구 추적이며 ADC 펌웨어 구현·회로 성능 검증이 아니다.
