Hall sequence PC exercise

Open a Visual Studio Developer Command Prompt in this folder, then run:

    cl /W4 /WX /TC hall_sequence.c /Fe:hall_sequence.exe
    hall_sequence.exe

Expected: 12/12 passed.
The example assumes A:B:C are bits 2:1:0 and sequence 110,100,101,001,011,010.
This is a PC-only example. It does not drive or protect a real motor.
For details and Korean explanations, see the accompanying Notion lesson.
