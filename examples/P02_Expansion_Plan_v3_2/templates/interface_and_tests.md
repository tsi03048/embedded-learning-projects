# 같은 측정 묶음의 전달 약속·시험 계획

제안 형식: D1,seq=104,tick=12400,raw=2600,state=W\r\n
generation0/1 / seq·tick32비트 / raw0..4095 / state1글자 / ASCII·CRLF.
seq는 정상 완료한 새 결과마다 증가하며 큐가 가득 차도 증가. tick은 main의 완료 관찰·DR 읽기 지점의 같은 시간원 기록.
raw·state·generation·seq·tick을 같은 큐 슬롯에 복사. active는 문장 완료까지 고정.
리셋 뒤 식별자 재사용·32비트wrap·부분 줄·SYNC 규칙은 송신기/PC에서 별도 정의한다.

|---|---|---|---|
|P02-T01|104→105는 연속,104→107은105·106 미관측; 원인은 미확정|미작성|미실행|

이 표의 송신 펌웨어·파서는 아직 구현하지 않았다. PC 길이 계산 결과로 통합 시험을 PASS 처리하지 않는다.
기존 P01-X의 설계를 연결한다. 새 원문 로그·실행파일·Commit과 E07 양식을 함께 남긴다.
