Synthetic zero-crossing threshold PC exercise
Open a Visual Studio Developer Command Prompt in this folder and run:
    cl /W4 /WX /TC hysteresis.c /Fe:hysteresis.exe
    hysteresis.exe
Expected: 10/10 passed. Indices start at zero; -1 means no detection.
All values and thresholds are hypothetical. This does not control a motor.
The Notion lesson contains the Korean explanation and limitations.
